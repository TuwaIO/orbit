# Пакети

Orbit Utils складається з одного основного пакета, незалежного від мереж (**L1**), і одного пакета для кожної платформи блокчейнів (**L2**). Встановіть основний пакет і лише пакети тих мереж, з якими працює ваш застосунок. Мережеві пакети оголошують свої Web3-бібліотеки як peer-залежності, тож ваш застосунок тримає лише одну копію `viem`, `@wagmi/core` чи `@solana/kit`.

Сторінка кожного пакета починається з README пакета (того самого тексту, що опубліковано в npm), за яким іде повний список його експортів. Сторінку кожної функції, типу й константи згенеровано з вихідного коду TypeScript та його JSDoc, тож довідник завжди відповідає випущеному коду. README пакетів і довідник подано англійською.
